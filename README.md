# Chatak Template Hub

> Community acoustic template library for the Chatak Eco-Acoustic Platform.

This repository provides **pre-curated bird call templates** that can be imported directly into Chatak's
Template Repository, enabling instant pattern matching without manual feature extraction.

## What's included

| File | Purpose |
|------|---------|
| `manifests/recordings.json` | Master catalogue of all recordings |
| `species/<code>/XC<id>/clip.wav` | Trimmed audio clip (5-15s, 22 kHz mono) |
| `species/<code>/XC<id>/features.json` | Pre-extracted acoustic feature vector |
| `species/<code>/XC<id>/roi.png` | Spectrogram ROI thumbnail |
| `species/<code>/XC<id>/metadata.json` | Recording metadata (recordist, location, quality) |

## Stats

- **54 species** - **253 recordings**
- All audio sourced from [Xeno-Canto](https://www.xeno-canto.org) (CC licensed)
- Features extracted with librosa (mode=full): MFCCs, chroma, spectral contrast, HPSS

## How to use in Chatak

1. Open **Template Repository** and click the **Hub** tab
2. Search for a species
3. Listen to the audio preview directly in the browser
4. Click **Download to Local** on any recording
5. Use the downloaded template in **Pattern Matching**

## Contributing

To add a new species:
1. Download recordings via Chatak's **Download from XC** feature
2. Run AED, select best events, extract features
3. Run `build-template-hub.ps1` and submit a pull request
